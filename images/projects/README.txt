PROJECT IMAGES — where your plots and figures go
================================================

Put plots/figures for each research project in a subfolder here:

  public/images/projects/thq/       -> CERN/ATLAS project plots
  public/images/projects/stf1434/   -> binary star figures
  public/images/projects/weather/   -> LSTM forecasting plots
  public/images/projects/galaxy/    -> galaxy classification results

Then open the matching markdown file in src/content/projects/ and
uncomment/edit the image lines, e.g.:

  ![Predicted vs. true di-tau mass](/images/projects/thq/predicted-vs-true.png)

Use PNG or JPG, ideally under ~300 KB each so pages stay fast.
